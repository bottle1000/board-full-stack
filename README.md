# Board Full Stack — Java/Spring 게시판과 API QA

Java 17 · Spring Boot · Spring Security/JWT · JPA · MySQL 기반 개인 게시판 프로젝트입니다.

**QA 지원 자료는 [API QA 기록](docs/qa/README.md)에서 확인할 수 있습니다.**

## QA에서 확인한 내용

- 입력 조건: 필수값, 제목 길이 200·201자, 목록 크기 50·51
- 권한: 작성자·다른 일반 사용자·관리자 역할별 요청
- 데이터: 요청 차단 후 원본 유지, 본인 삭제 후 논리 삭제와 조회 차단
- 결함: 일반 USER의 관리자 API 요청에서 기대 403 대신 500이 반환되는 오류 응답

기존 수동 15건 기록과 2026-10-19 새 직접 검증을 분리해 정리했습니다. 결과보고서에는 Postman 응답과 SQL 캡처를 연결했습니다. 과거 실패 원본 미확보와 검증 버전의 한계도 표시했습니다.

## 구현과 테스트 자료의 관계

공개 소스는 개발 프로젝트이며 QA 자료는 별도 docs/qa 경로에 있습니다. 관리자 오류 응답 수정은 문서 작성 시 로컬 변경 상태로, 공개 main 반영을 완료했다고 표시하지 않았습니다. 수정 차이와 검증 범위는 QA 문서에 설명했습니다.

## 실행 환경

Java 17, MySQL, Gradle Wrapper를 사용합니다. DB 접속 정보와 JWT 설정은 개인 실행 환경에서 구성해야 합니다. 이 QA 문서 추가본에는 실제 비밀번호·접속 키·토큰을 포함하지 않았습니다. 상세 API는 프로젝트의 컨트롤러와 요청 DTO를 기준으로 확인합니다.
