# BUG-003 일반 사용자의 관리자 API 접근 오류 응답

## 기존 기록과 재현 조건

2026-10-15 개인 수동 테스트 기록. 유효한 일반 USER 계정으로 GET /api/admin/users를 요청했을 때 기대한 403 대신 500 / COMMON_INTERNAL_SERVER_ERROR가 반환됐습니다. 최초 500 캡처는 미확보입니다.

권한이 없는 사용자의 회원 목록 접근을 거부하되 권한 부족을 나타내는 403을 반환하는 것을 기대결과로 정했습니다. 500이라는 사실만으로 관리자 권한 우회나 정보 유출이 발생했다고 주장하지 않습니다.

## 원인과 수정

AccessDeniedException이 일반 예외 처리 경로로 전달되는 문제에 대해 전용 처리기를 추가하여 403 / AUTH_FORBIDDEN으로 매핑했습니다. [수정 차이](관리자403_수정내용.patch)를 이번 코드 수정본에 반영했습니다. [2026-10-20 MockMvc 회귀 검사](코드회귀_20261020/결과보고서.md)에서 수정 전 1개 실패·수정 후 5개 통과를 확인했습니다. 당시 원본 500 캡처와 이번 재현 기록은 구분합니다.

## 검증 구분

- 원본 포트폴리오: 수정 후 USER 요청의 403 및 AUTH_FORBIDDEN 확인 기록. 관련 회귀 3건은 타인 수정·삭제와 목록 크기 제한.
- AI 추가 검증(2026-10-18): 격리된 실제 Spring Boot·MySQL 환경에서 USER와 ADMIN 요청을 수정 전후 각각 실행. USER 500→403, ADMIN 200→200과 회원 목록의 DB 일치 확인. 기존 수동 15건에 합산하지 않음.
- 수정 전 재현용 빌드는 기준 커밋 52185f3c5ae30bbb542fd64cf3fd7dde51f4b0fd의 예외 처리기를 사용한 복사본입니다. 최초 테스트 당시의 전체 환경을 복원한 것은 아닙니다.
- AI의 MockMvc 검사 5개 통과는 모킹을 사용한 코드 검사이며 실제 JWT·DB 검증과 구분합니다.

전체 원본 결과는 별첨 지원 포트폴리오 증빙 자료에 보관했습니다. 이 공개 문서의 요약만으로 당시 원본 응답이 모두 공개됐다고 해석하지 않습니다.

## 심각도와 우선순위: 사후 검토안

2026-10-19 정리한 S3(중간) / P2(계획 수정) 제안입니다. 접근은 거부되지만 응답 분류가 잘못된 문제이므로, 필수 데이터 누락보다 낮게 평가했습니다. API 응답 계약 및 클라이언트 연동 정리 시 수정하는 우선순위를 제안합니다. 실제 운영 장애·권한 우회·개인정보 유출이 확인되면 재평가해야 합니다. 당시 확정 등급이나 현재 미해결 상태를 뜻하지 않습니다.
