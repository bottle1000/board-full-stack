# 관리자 권한 오류 처리 회귀 검사

실행일: 2026-10-20. 수행: AI 에이전트. 기존 직접 수동 35건과 별도 기록입니다.

## 변경과 결과

`AccessDeniedException`을 전용 처리해 `403 / AUTH_FORBIDDEN`을 반환하도록 수정했습니다. 그 외 예외의 기존 분류는 유지합니다.

| 검사 | 수정 전 | 수정 후 |
|---|---|---|
| USER의 관리자 목록 접근 | 기대 403, 실제 500으로 실패 | 403·AUTH_FORBIDDEN, 서비스 호출 없음 |
| ADMIN의 관리자 목록 접근 | 통과 | 200·success=true, 서비스 호출 확인 |
| 기존 게시글 권한 오류 | 통과 | 403·POST_FORBIDDEN |
| 필수 입력 오류 | 통과 | 400·COMMON_INVALID_REQUEST |
| 실제 내부 예외 | 통과 | 500·COMMON_INTERNAL_SERVER_ERROR, 응답에 내부 예외 메시지 미노출 |

수정 전 5개 중 4개 통과·1개 실패, 수정 후 5개 모두 통과했습니다. 같은 검사 집합으로 수정 전후를 비교했습니다. 새 결함 1건 발견이나 기존 35건 전체 재실행을 뜻하지 않습니다.

## 범위

실제 AdminController의 메서드 권한 설정과 GlobalExceptionHandler를 MockMvc로 검사했습니다. AdminService는 Mockito 모킹이며 SecurityContext에 역할을 설정했습니다. JWT 필터·실제 로그인·DB·네트워크 서버 요청은 이번 검사에 포함하지 않았습니다. 10월 18일 실제 JWT·DB 추가 검증과 구분합니다.

기준 커밋: 08c06cd92015444d5b6fa06ba07e1b9d0c931cf2. 수정 전에는 이 커밋의 예외 처리기를 사용했습니다. 기존 테스트의 세부 결과와 수정 후 소스 해시는 [검사결과.json](검사결과.json)에 기록했습니다. 원본 JUnit XML은 로컬 작업 기록에 보존했고 JSON은 결과 요약입니다.

## 실행

Java 17 환경에서 프로젝트 루트 기준:

```bash
./gradlew test --tests com.boardfullstack.global.exception.AccessDeniedRegressionTest
```

전체 테스트에는 별도 DB와 대량 데이터 관련 테스트가 있어 이번에는 위 검사 클래스만 실행했습니다. 코드 수정본과 검사 파일을 함께 준비했으며 GitHub 업로드 완료 여부는 별도 게시 기록으로 관리합니다.
