## 케이스 이름 구분

50 요청의 사용자 Postman 이름은 API16 목록 size 정상입니다. 기존 보완 문서에는 API16을 관리자 정상 접근 대조에도 사용하므로, 새 기록은 A08-LIST50·A08-LIST51로 구분했습니다. 원본 요청 이름과 이미지는 바꾸지 않았습니다. 51은 기존 API13 조건을 새로 실행한 결과이며 과거 결과를 덮어쓰지 않습니다. Postman 자동 검사 통과 여부는 화면에 없으므로 주장하지 않습니다.
