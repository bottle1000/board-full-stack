## 범위와 출처

- 기존 수행일 2026-10-15: 수동 15건, 최초 14건 통과·1건 실패. 결함 재테스트 1건·관련 회귀 3건의 기록을 전체 15건 재실행과 구분합니다.
- 신규 직접 실행일 2026-10-19: 지원자가 Postman·MySQL에서 실행한 캡처 11장. 각 보고서에 입력 조건, 실제 결과, 증거와 한계를 연결했습니다.
- 테스트·SQL 초안, 코드 분석·수정, 문서 정리에 AI를 활용했습니다. AI의 별도 실행은 직접 수행 실적에 합산하지 않았습니다.
- 당시 개별 실행표는 작성하지 않았으며 최초 일부 실패 원본도 미확보입니다. 과거 기록을 새 결과로 덮어쓰지 않았습니다.
