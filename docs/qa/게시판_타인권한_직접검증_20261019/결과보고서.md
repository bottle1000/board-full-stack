# A06 타인 게시글 수정·삭제 차단: 사용자 직접 검증

2026-10-19 지원자가 Postman과 MySQL에서 실행하고 제출한 원본 6장을 대조했습니다. AI가 해당 요청을 직접 실행한 결과가 아닙니다.

## 실행 조건

- 대상 글: postId=100013. 작성자 A는 응답상 QA A, authorId=10316입니다.
- 수정·삭제 URL의 실제 postId가 100013이고, 두 요청 모두 작성자 A와 다른 일반 계정 B 토큰을 사용했다고 사용자가 명시 확인했습니다. 화면에는 변수명만 보이므로 해당 설명을 근거로 연결했습니다.
- 원본 제목: QA-A06 원본 제목 / 내용: QA-A06 원본 내용.
- 수정 시도 제목: QA-A06 변경 시도 / 내용: QA-A06 B의 변경 시도.
- baseUrl 실제 주소, B의 사용자 ID, 실행 소스 버전은 미확인입니다. 비밀번호·토큰 원문은 수집하지 않았습니다.

| 단계 | 실제 응답 | DB 조회 | 판정 |
|---|---|---|---|
| A가 글 생성 | POST 200, postId=100013, authorId=10316 | 원본 제목·내용, is_deleted=0 | 사전 데이터 확인 |
| B가 A 글 수정 시도 | PUT 403, POST_FORBIDDEN, data=null | 작성자·제목·내용 동일, is_deleted=0 | 기대결과 일치 |
| B가 A 글 삭제 시도 | DELETE 403, POST_FORBIDDEN, data=null | 작성자·제목·내용 동일, is_deleted=0 | 기대결과 일치 |

응답의 timestamp는 각각 2026-10-19T16:42:53.036402, 16:51:53.962164, 16:53:07.420102입니다. 타임존 오프셋이 없으므로 변환하지 않았습니다. SQL 세 장은 안내 순서대로 요청 전·수정 후·삭제 후 자료로 연결했으며 개별 조회 시각은 캡처에 없습니다.

## 판정 범위

선정한 동일 게시글에 대한 타인 수정·삭제 2건에서 권한 오류 응답과 데이터 유지가 기대에 일치했습니다. 403 자체와 원본 보존을 각각 확인했습니다. 전체 API·모든 권한 조합·보안 검증을 완료한 것으로 확대하지 않습니다. 기존 15건(총 35건)의 과거 수행 기록에 합산하지 않습니다. 기존 API09·API10의 상세 증빙을 새 날짜의 직접 실행으로 보완한 것입니다.

## 포트폴리오 반영 문장

작성자 A와 일반 계정 B를 분리해 동일 게시글의 타인 수정·삭제 요청을 실행했습니다. 두 요청의 403·POST_FORBIDDEN을 확인하고, 요청 전후 SQL에서 작성자·제목·내용·삭제 상태가 유지되는지 대조했습니다.
